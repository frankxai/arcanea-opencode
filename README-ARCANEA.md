## 🚀 Quick Start

### Installation

```bash
# Install Arcanea Intelligence OS
npm install -g @arcanea/opencode

# Verify installation
arcanea-opencode --version
```

### First Activation

```bash
# Activate Draconia for aggressive refactoring (ultrawork mode)
arcanea-opencode activate draconia --mode ulw --parallel

# Activate Lyria for surgical design (lumina mode)  
arcanea-opencode activate lyria --mode lumina

# Check system status
arcanea-opencode status

# View Ten Gates progression
arcanea-opencode gate
```

### Claude Code Integration

```bash
# Integrate with Claude Code (seamless auto-load)
arcanea-opencode integrate --platform claude

# Skills auto-load from ~/.claude/skills/
# Agents auto-load from ~/.claude/agents/
# Use /lumina, /nero, /ulw directly in Claude
```

### OpenCode Integration

```bash
# Integrate with OpenCode desktop/cli
arcanea-opencode integrate --platform opencode

# Arcanea becomes available as OpenCode plugin
# Full Lumina-Nero engine with Guardian expertise
```

## 🚀 Installation & Setup

### Prerequisites
- Node.js 18+ or Bun runtime
- OpenCode installation OR Claude Code access
- Git for version control integration

### Install Arcanea Intelligence OS
```bash
# Method 1: NPM (Recommended)
npm install -g @arcanea/opencode

# Method 2: Bun (Faster)
bun install -g @arcanea/opencode

# Method 3: Development clone
git clone https://github.com/frankxai/arcanea-opencode
cd arcanea-opencode && npm install && npm link
```

### Post-Installation Setup
```bash
# Verify installation
arcanea-opencode --version

# Initialize Arcanea configuration
arcanea-opencode integrate --platform opencode

# Or Claude Code setup  
arcanea-opencode integrate --platform claude

# Check system status
arcanea-opencode status
```

## 🔮 Troubleshooting

### **Guardian Won't Activate**
```bash
# Check available Guardians
arcanea-opencode gate

# Verify spelling
arcanea-opencode activate lyssandria  # not lissandria

# Check system status
arcanea-opencode status
```

### **Integration Issues**
```bash
# Re-run integration
arcanea-opencode integrate --platform claude  # or --platform opencode

# Check paths
ls ~/.claude/skills/     # Claude integration
ls ~/.config/opencode/   # OpenCode integration
```

### **Performance Issues**
```bash
# Reduce concurrency
arcanea-opencode activate draconia --parallel --max-concurrency 2

# Use sequential mode  
arcanea-opencode activate lyria --no-parallel

# Clear elemental spirit cache
arcanea-opencode --clear-cache
```
